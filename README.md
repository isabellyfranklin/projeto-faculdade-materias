#  Projeto Faculdade - Matérias

Olá, me chamo Isabelly e eu fiz esse site para me ajudar a estudar as matérias da faculdade e me ajudar a revisar elas.

##  Link do site:
> https://isabellyfranklin.github.io/projeto-faculdade-materias/

##  Funcionalidades
- Organização dos estudos por trimestre (1° ao 6° trimestre .....)
- Listagem das matérias de cada trimestre com quantidade de aulas
- Contagem total de aulas por trimestre
- Resumos de cada aula/matéria para revisão do conteúdo
- Quiz ao final de cada resumo para fixação do conteúdo estudado
- Navegação para a página detalhada de cada trimestre
- Aviso de conteúdo em construção para trimestres ainda não disponíveis

##  Tecnologias utilizadas
- **HTML5** — estrutura semântica da página
- **CSS3** — estilização do layout e dos cards
- **JavaScript (Vanilla)** — lógica de navegação, exibição dos dados e funcionamento do quiz
